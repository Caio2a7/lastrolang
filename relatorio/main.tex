\begin{resumo}
  Este documento especifica a linguagem Lastro nos níveis léxico, sintático e
  semântico e descreve o compilador que a traduz para um C simplificado, aceito
  pelo \texttt{gcc} sem erros. Ele registra as principais decisões de
  implementação, as estruturas de dados e as verificações feitas sobre os
  programas, a organização do código-fonte, as instruções de geração e uso, as
  limitações da linguagem e da implementação e os pontos de melhoria futura.
\end{resumo}

\begin{abstract}
  This document specifies the Lastro language at the lexical, syntactic and
  semantic levels and describes the compiler that translates it into a
  simplified C accepted by \texttt{gcc} without errors. It records the main
  implementation decisions, the data structures and the checks performed on
  programs, the source code organization, build and usage instructions, the
  limitations of the language and of its implementation, and future work.
\end{abstract}
